# Circular Navigation

A small front-end practice project: an animated circular navigation menu built with **HTML, CSS and vanilla JavaScript**.

## Features

- Eight icon-based menu items arranged in a circle
- Animated opening and closing with staggered transitions
- Highlighted selection
- Dark background with green accents
- No build tools or package installation required

## Run locally

Download the project and open `index.html` in a modern browser.

An internet connection is required to load [Ionicons](https://ionic.io/ionicons) from the CDN. The project uses Ionicons version 7.1.0.

## Usage

1. Click the central **+** icon to open the menu.
2. Click an icon to highlight that item.
3. Click the central icon again to close the menu.

This is a visual interaction demo. The links are placeholders (`#`) and do not open separate pages.
